# 当前绘画路径平滑实施计划

日期：2026-11-04。状态：完成附件与当前源码核对，尚未实施算法或验证实机效果。

参考用户附件 `path-smoothing-design.md`，本文件将其中的候选方案收敛为当前仓库的实施顺序。附件中的诊断数值属于历史离线结果，本轮未重新运行；本文的参数和改善目标均待验证。

## 1. 目标与判断

先消除目标路径中像素台阶造成的反复转向，再降低运动对末端的激励，最后按反馈与墨迹差异处理夹持和接触问题。路径几何、轨迹跟踪、笔具变形可能叠加，目前没有数据可以确定各自占比。

数字轨迹最终仍然需要离散采样。目标是让路点来自光滑曲线，并将折线近似误差控制到指定范围，而不是追求没有离散点。单纯增加路点、减小笛卡尔插值步长或降低绘画速度，都不会消除原目标折线里的小转角。

建议主线采用“受约束三次 B 样条拟合 → 弧长采样 → 最终折线验证 → 现有 MoveIt 执行”。原生 MoveL／MoveC 单列为执行方式对照实验，不作为第一阶段依赖。

## 2. 当前源码事实及附件修正

| 环节 | 已核对的当前行为 | 实施影响 |
| --- | --- | --- |
| `curves.py::_smooth_span` | 三轮 Chaikin 削角，再做折线简化 | 不保证曲率平滑，不能靠继续细分消除残余折角 |
| `simple_lines.py::smooth_supported_path` | 端点、尖角和约 4 mm 窗口接点固定，各窗口独立处理 | 平滑段存在人为边界，没有接点切向连续约束 |
| `geometry.py::resample` | 保留原顶点，只细分长线段 | `step_mm=1.0` 表示最大点距，不是等弧长重新取点 |
| `stroke_graph.py::trace_strokes` | 连接交汇簇并按方向将边接成笔画，返回点列、闭环和保护标记 | 需补充内部图连接点的元数据，不能只固定最终笔画首尾 |
| `vectorize.py::order_strokes` | 改变笔画方向、闭环起点，并合并共享端点 | 排序与合并后仍需检查固定结构点和边界语义 |
| `planner.cpp::cartesian / limit_speed` | 笛卡尔插值、IPTP 计时，再整段时间缩放 | 当前没有图像去噪、曲率局部限速或 jerk 平滑 |
| `SDKTransport.send` | MOVE J 发送，使用 `firmware_speed_percent`；当前设备文件值为 100 | 附件“SDK 固定 10%”已经过时；实验需记录运行实例实际值 |
| 当前实机任务记录 | `output/draws/20261103_232337_135430` 保存了原图、任务、配置与执行记录 | 优先作为真实图案基线；附件的 A5 历史统计另保留作回归 |

近期任务与工作配置中，声明笔宽为 0.1 mm，TCP 向量长度约 163 mm；`config/real.yaml` 仍是另一套模板。以上是文件记录，不证明笔具现状未变化。比较使用对应任务快照，并在实机执行前核对当前纸面、笔具与标定。不同纸面比例下重新计算毫米指标，不直接套用附件约 0.207 mm 的直线波动基线。

## 3. 第一阶段：几何平滑

### 3.1 先建立可比较的基线

保存近期任务的原线稿、配置和旧路径，不覆盖旧产物。生成多方向斜线、圆弧、闭环、V 形尖角、直角、交汇与近邻笔画等固定输入。

在相同尺寸、分辨率和笔宽下测量旧算法；直线指标统一按首尾各排除 2 mm 计算，不按固定点数裁剪。保存整体与局部放大叠图、法向波动、固定物理尺度的转向变化、最大偏差与结构检查结果。

同时用数学坐标直接生成直线和圆弧作为执行基准，绕过图像取线。它们用于后续分辨“目标路径已有噪声”和“理想目标也会抖”。

### 3.2 补齐结构约束

在图追踪阶段保留端点、分叉代表点及其在接续笔画中的位置，跟随反转、闭环换起点和合并更新。只保留最终笔画端点不够。

尖角使用毫米尺度邻域识别，先验证现有 `_corner_indices` 对斜线与圆弧的误判率。真实尖角作为固定点，两侧分别拟合；分叉各支路可有不同切线。普通平滑段取消每隔 4 mm 的强制固定点。

没有尖角的闭环采用周期约束；有尖角的闭环从真实尖角分段。现有自交路径第一版继续保留原几何，并明确记录为未平滑。短五官和厚黑点保留当前表达，纳入回归检查。

### 3.3 拟合连续曲线

两个结构锚点之间先尝试直线，必须同时通过最终偏差、黑线支撑和结构保护。其余段采用参数三次 B 样条，同时拟合 x、y，避免将轮廓当作单值 y(x)。

拟合使用累计弦长参数、按弧长分配的数据权重和二阶导正则项；端点与内部固定结构点使用等式约束。明确参数归一化和正则项的尺度约定，防止长短笔画因同一个平滑参数而产生不同的非预期效果。平滑强度与几何容差分开定义。

使用项目支持的 SciPy 版本范围内的基函数与线性代数能力实现，不依赖本机偶然安装的较新接口。无尖角闭环保证接缝位置、切向及拟合所需的周期连续性。确需分块求解时，在人工接点约束位置和切向，必要时约束二阶导；不能重新引入独立窗口削角。

### 3.4 从曲线重新生成路点

新增曲线专用采样函数，计算弧长与参数的对应关系，按最大点距及弦误差自适应生成路点。保留真实尖角和固定连接点，去掉连续重复点，闭环只保留约定的末尾闭合点。

曲线到折线的误差用分段控制点包络和有界细分检查，不能只检查中点。采样结果保留来源参数，供最终误差检查使用。原 `resample` 保持原有折线加密契约，不全局替换。

### 3.5 验证最终输出及失败处理

验收对象是最终写入任务的折线。沿用 `_deviation` 的参数折线比较思路，将输入参数和输出来源参数统一后合并断点，检查整段最大偏差。拟合误差和采样误差不能各自用满总预算。

同时校验黑线支撑、端点与分叉固定、真实尖角、闭环、白色高光、断口、单笔及跨笔画的新交叉或连接。跨笔画比较以输入已有交叉关系为基准，不能仅靠黑线支撑检查代替。排序、合并后再执行相关最终检查。

对失败段按固定的尝试次数和细分预算收敛；局部重拟合需保持人工接点的连续性，无法满足时保留原段。输出笔画编号、区间、失败原因和回退长度，区分 `line`、`spline`、`preserved`，不把回退记为平滑成功。

### 3.6 首轮参数与兼容性

| 项目 | 初始候选 | 比较方式 |
| --- | --- | --- |
| 最终几何偏差 `image.simplify_mm` | 0.15 mm | 比较 0.10、0.15、0.20 mm，均须通过原黑线支撑 |
| 最大路点距离 `image.step_mm` | 1.0 mm | 几何方案确定后单独比较 0.5 mm |
| 曲线离散弦误差 | 0.03 mm | 计入总几何预算；比较 0.03–0.05 mm |
| 绘画速度、运动缩放、固件速度 | 使用所选基线的实际记录 | 新旧几何对照中保持一致 |
| 笔宽、填孔、毛刺修剪、纸面与 TCP | 使用同一配置快照 | 不将其他取线或标定调整混入几何收益 |

这些值是实验起点，不是保证的绘画精度。0.1 mm 声明笔宽下更需验证细节与白区保护；不通过时分析约束冲突，不放宽支撑掩码来获得通过。

`smoothing_span_mm` 在新流程中废弃，不能改名义为样条控制点间距。实现时同步处理配置读取、调参白名单、默认配置、历史配置迁移和快照；旧配置提供明确迁移提示。旧算法只作为基准或其他尚未迁移模式的明确实现，避免同一模式长期隐式混用两套算法。

## 4. 第二阶段：降低运动激励

几何通过后，对同一条曲线进行轨迹检查与实机对照。以路径曲率建立局部速度上限，使用 `v² × |κ| ≤ a_normal_max` 约束法向加速度，并结合关节速度和加速度限制进行前向加速、后向制动。真实尖角若要求精确经过，应减速至停止。

在直接生成绘画轨迹的 `Planner::cartesian` 链路内评估 jerk 平滑。每次时间参数化后统一生成和复查位置、速度、加速度与时间；不能只改 OMPL 适配器就认定绘画段已生效。修改后检查实际控制器插值下的关节限制、轮廓、笔尖高度及碰撞，注明采样验证分辨率。

将“曲线是否光滑”和“加速是否激起余振”分开验证。几何对照完成后，固定几何分别扫描绘画速度、加速度和 jerk 限额，每次只改变一个因素。与提速计划中的局部限速工作合并实现，避免建立两套重计时逻辑。

## 5. 第三阶段：跟踪、夹持与接触

同步记录目标轨迹、关节命令、原始关节反馈、控制器期望／实际状态、实际发送间隔及运行中的固件速度参数。先核对当前话题与字段；现有浏览器反馈笔迹有约 0.2 mm 点距筛选和 0.7 mm 显示线宽，不能承担亚毫米抖动定量测量。

用同一模型和 TCP 从关节反馈恢复笔尖轨迹，分别比较目标几何、反馈轨迹和透视校正后的真实墨迹。报告沿路径延迟与法向轮廓误差，不能把延迟直接当作横向抖动。模型反馈不能观测笔杆弹性变形。

夹持先处理横向间隙和过长悬伸，保持伸出长度可重复；需要轴向顺应时使用有导向、有限行程的结构。改变夹具或伸出长度后重测 TCP，再单独做对照。断墨、积墨、压纸和高度漂移通过接触实验定位，横向曲线拟合不能解决这些问题。

## 6. 原生 MoveL／MoveC：独立试验分支

先比较数学直线、单圆弧，再比较同一圆弧拆成两段、相切不同半径圆弧、直线接圆弧和闭环，最后才测试下颌／镜框。记录段内轮廓与段间掉速、停顿、墨点，至少重复三次。按实际耗时或实际笔尖速度配平比较，不用相同速度百分比代替。

现有 MOVE J 发送会覆盖原生模式，试验必须独占运动发送。需复用标定、反馈与停止能力，并为原生长段定义心跳、反馈超时、完成和取消判定；原有关节命令 250 ms 看门狗不能直接套用，也不能简单关闭。退出后用新反馈对齐现有关节控制目标。

完整检查原生曲线的可达性、工具净空和姿态；另一条 MoveIt 轨迹通过不等于原生轨迹通过。只有多段衔接与取消语义得到确认且画质通过，才考虑正式原生后端。单弧画得好、每段仍明显停顿时，保留作基准实验。

第一轮离线目标：合成直线中段法向峰峰值相对同条件基线降低至少 70%，最终路径最大偏差不超选定容差，固定结构点保持，圆弧接缝连续，无新交叉、跨断口或高光侵入。复用现有固定 0.5 mm 弧长转向指标，并增加更细固定尺度的波动检查；点数下降和逐点大转角减少不能单独作为成功依据。

保持现有覆盖、分块覆盖和名义时间门槛。报告保留原段的数量与长度比例，人工检查同一人像的下颌、镜框、五官和发尖。圆弧同时检查半径偏差和离散弦误差。

离线通过后，以数学图形、真实轮廓局部、完整人像的顺序验证，每种实机条件至少三次。第一阶段有离线结果但尚无纸面结果时，状态写为“几何修复已验证，实机效果待验证”。

实施后的旧任务 YAML 不会自动改变。必须从原线稿和核对后的标定重新生成任务，再完整规划；保留旧任务供回退与对照。

本轮仅新增此计划文件，未修改绘画算法、工作配置或运动后端，也未连接 CAN 或发出运动命令。当前宿主 Python 缺少 OpenCV，本轮没有运行几何复现或测试；实施时使用项目容器环境完成验证。
