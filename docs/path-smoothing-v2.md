# 第二轮目标路径平滑

2026-11-05。针对用户反馈的“小幅高频变成大幅低频”，本轮只优化生成的二维目标几何，没有运行机械臂，也没有修改速度、加速度、标定、纸面或笔宽。

当前任务接口仍保存离散路点，所以输出是曲线的折线近似。正常的离散弦段、应保留的艺术尖角，与像素噪声造成的反复转向是不同问题。本次减少后者，不宣称消除了所有折线，也不把目标几何改善当成实机墨迹改善。

## 回滚

修改前创建 Git 标签 `before-path-smoothing-v2`，指向 `cc6f5836d0332f93397c93403d9496398cc789ff`。这是通过 `git stash create` 取得的非破坏性快照，也包含当时尚未提交的标定工作；没有清空工作区或改变原有暂存状态。

本轮实现单独提交，并标记 `path-smoothing-v2`。撤销本轮实现可用 `git revert path-smoothing-v2`；不要用全仓 `reset --hard` 覆盖其他工作。忽略的历史任务和本机配置仍保留在磁盘。旧任务文件不会自动变成新路径，需重新从线稿生成。

## 算法变化

原流程为满足偏差和黑线支撑约束，重试时同时缩小控制点间距、减弱正则化。后者按平滑长度的四次方作用，每轮减半会使正则系数降低到 1/16，长轮廓可能重新追随像素骨架起伏。

新版仍保存原流程的第一个合格解作为基线，然后固定控制点布局、端点、尖角及图连接约束，独立尝试更强正则化。平滑长度最多恢复到首轮的 0.6 mm，不扩大首轮尺度。先检查四个对数间隔候选，再在最佳候选附近最多检查两个候选；搜索次数有界，不假定支撑和拓扑约束单调。

所有候选重新检查最终折线偏差、黑线支撑和自交。将最终折线分别按约 0.25、0.5、1 mm 弧长间隔采样，统计转向能量 `sum(turn² / local_distance)`；只有三尺度总能量下降、任一尺度相对基线退化不超过 5% 时才替换。点数不作为平滑评分。该指标限制目标路径粗糙度，不是所有频段摆幅或实际墨迹的数学保证；宽幅形变仍由总偏差界和解析图形回归共同约束。

整笔拼合和全图连接保护均采用两阶段检查：先验证基线，再尝试细化。细化引入新的交叉、接触或支撑失败时，恢复已验证基线及其真实诊断，不整笔退回像素骨架。原基线本身失败时仍保留原始几何。simple、faithful 两个入口均已接入；点状标记的表达保持原逻辑。

诊断版本更新为 `constrained_cubic_bspline_v2`，增加细化前后正则强度、控制间距、最大偏差、三尺度转向能量、搜索次数和细化回退原因。

代表性长区段（编号属于排序前诊断）在 0.25 mm 尺度的转向能量降幅：47.11 mm 长段 58.1%，53.85 mm 长段 44.5%，65.90 mm 长段 36.0%，52.81 mm 闭环 36.6%。这些是局部目标几何指标，不能当作整幅画像或实机摆幅的降幅。

已有三方向理想直线的目标法向波动没有变化，分别为 0.02726、0.00237、0.02003 mm。无需重试即可通过的基线不会为了追求更少转折而继续强化平滑。

## 验证和复现

- 全套 Python 测试：461 项通过，1 项既有配置迁移警告。
- 改动文件 Ruff 检查、格式检查、`git diff --check` 通过。
- 新增量化扁椭圆回归：逆向累计转向由 v1 的 8.451 rad 降到 1.543 rad，解析椭圆法向偏差最大 0.06261 mm，约 5 mm 尺度宽波偏移最大 0.03019 mm。该测试在旧版本失败、新版本通过。
- 新增量化圆宽波偏移守门、开放轮廓端点/内部锚点保持，以及细化新接触时恢复基线曲线的回归。
- 从新生成的任务 YAML 还原纸面笔尖路点，验证与评价用最终路径一致，误差小于 `1e-9 mm`。

产物位于 `output/path-smoothing/v2-20261105/`：`v1/` 是修改前保存的结果，`v2/` 是新任务、配置、诊断、预览与路径；`comparison.json` 为最终对照，`compare.py` 可复算指标、检查任务还原并生成图表。
